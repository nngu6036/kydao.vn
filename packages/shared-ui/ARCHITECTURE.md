# shared-ui purpose

`shared-ui` contains reusable cross-app Angular UI pieces and larger content sections.

Examples:
- toolbar
- page shell
- section header
- link strip
- empty state
- search box
- player card
- external links cloud
- top magazine bar
- site header
- featured tabs section
- tournament status section
- three-column link section
- player category directory
- search hub section
- magazine section
- friend links section
- footer
