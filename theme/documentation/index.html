Installation & Setup

Follow these steps to set up the Angular template on your local machine:

Prerequisites

  • Node.js (version 18.x or higher recommended)
  • npm or yarn package manager
  • Angular CLI (install via npm install -g @angular/cli)
  • Basic knowledge of Angular and TypeScript

Installation Steps

  1. Extract the downloaded zip file to your desired location
  2. Open terminal/command prompt and navigate to the project folder
  3. Run npm install to install all dependencies
  4. Run npm start or ng serve to start the development server
  5. Open your browser and visit http://localhost:4200

Available Commands

  • ng serve - Start development server (aliases: npm start)
  • ng build - Build for production
  • ng test - Run unit tests
  • ng lint - Lint and fix files

Angular Project Structure

This template follows the standard Angular project structure. The application is organized into modules/standalone components, services, and assets for better maintainability and scalability.

Folder Structure

diziti-angular/
├── src/
│   ├── app/             # Main application code
│   │   ├── components/  # Reusable components (Header, Footer, etc.)
│   │   ├── pages/       # Route-level components (Home, About, etc.)
│   │   ├── shared/      # Shared directives, pipes, services
│   │   ├── app.component.ts
│   │   ├── app.routes.ts # Routing configuration
│   │   └── app.config.ts # Application config
│   ├── assets/          # Static assets (images, styles, fonts)
│   │   ├── scss/
│   │   ├── images/
│   │   └── ...
│   ├── index.html       # HTML entry point
│   ├── main.ts          # Bootstrapping entry point
│   └── styles.scss      # Global styles
├── angular.json         # Angular Workspace config
├── package.json         # Dependencies and scripts
├── tsconfig.json        # TypeScript config
└── README.md

Angular Components and Logic

This template uses TypeScript and Angular's powerful component model. Components are the building blocks of the UI.

Application Bootstrapping (main.ts)

import { bootstrapApplication } from '@angular/platform-browser';
import { appConfig } from './app/app.config';
import { AppComponent } from './app/app.component';

bootstrapApplication(AppComponent, appConfig)
  .catch((err) => console.error(err));

Component Logic Example

import { Component, OnInit } from '@angular/core';

@Component({
  selector: 'app-hello',
  standalone: true,
  template: `<h1>Hello, {{name}}!</h1>`
})
export class HelloComponent implements OnInit {
  name: string = 'World';

  ngOnInit() {
    console.log('Component initialized');
  }

  changeName() {
    this.name = 'Angular';
  }
}

Changing Images

To change any images of the website

  1. Carefully collect the source name of the image (i.e. hero.jpg)
  2. Open the file called images.
  3. Find the particular image file.
  4. Replace the file with your image.
  5. Make sure that the file name does not change.The file name should be the same.

Changing Colors

We have used scss for this project to write css. If you are familiar with scss you should customize only the .scss files. The Angular build process automatically handles SCSS compilation.

  • Changing default template colors

Changing default template colors

  1. Open the variable.scss file from assets > scss > _variables.scss folder with a text-editor.
  2. Change the right-side values of the variables to change any default colors of your site.
  3. Save your file.

Building for Production

When you're ready to deploy your application, follow these steps:

Build Process

  1. Run ng build in your terminal
  2. Angular will create an optimized production build in the dist/ folder
  3. All assets will be minified and optimized
  4. The build is ready to be deployed to any static hosting service

Deployment Options

  • Netlify: Drag and drop the dist folder (specifically the folder inside dist, e.g. dist/project-name/browser) or connect your Git repository
  • Vercel: Import your project and deploy with zero configuration
  • GitHub Pages: Use angular-cli-ghpages package to deploy
  • Traditional Hosting: Upload the dist folder contents via FTP

Environment Variables

Angular uses environment.ts files for configurations (or modern loaders):

export const environment = {
  production: false,
  apiUrl: 'https://api.example.com'
};
